DesktopOrganizer

A Windows desktop organizer: group your desktop icons into movable, resizable panels that live on the desktop, behind your other windows.

Support

Questions, bug reports, suggestions: e.smirnov@protonmail.com.

For a bug report, please attach the newest file from your logs folder (Settings → About → Open logs folder). The log contains no file names or user names.

Good to know

  • The app runs in the notification area and has no main window. Right-click the tray icon for Settings and Exit.
  • Files you drop into a panel are moved off the desktop into C:\Users\<you>\DesktopOrganizer\PanelItems and come back when you drag them out. That folder is yours and stays in place if you uninstall the app.
  • Double-clicking an empty area of the desktop hides the standard desktop icons; double-click again to bring them back.
  • To start DesktopOrganizer with Windows, enable it in Settings → Apps → Startup after the first launch.

DesktopOrganizer

Органайзер рабочего стола Windows: значки собираются в перемещаемые панели, которые живут на рабочем столе позади остальных окон.

Поддержка

Вопросы, ошибки, предложения: e.smirnov@protonmail.com.

К сообщению об ошибке приложите самый свежий файл из папки журналов (Параметры → О программе → Открыть папку журналов). В журнале нет имён файлов и имени пользователя.

  • Приложение работает в области уведомлений, главного окна нет. Параметры и Выход — в меню значка.
  • Файлы, перетащенные в панель, перемещаются с рабочего стола в C:\Users\<вы>\DesktopOrganizer\PanelItems и возвращаются, когда вы перетаскиваете их обратно. Папка остаётся при удалении приложения.
  • Двойной клик по пустому месту рабочего стола скрывает стандартные значки, повторный — возвращает.
  • Автозапуск включается в Параметры → Приложения → Автозагрузка после первого запуска.
